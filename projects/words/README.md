# Слова

Адаптивный тренажёр английских слов без зависимостей и сборки.

## Запуск

Откройте `index.html` в браузере. Для локального сервера можно выполнить в этой папке:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

Словарь, интервалы и статистика хранятся в `localStorage` браузера. При первом запуске приложение также пробует импортировать массивы из ключей `words`, `slova`, `vocabulary` и `savedWords`, затем использует стартовый словарь.

## Редактирование

Вся логика, разметка и стили находятся в `index.html`. Стартовые слова задаются в массиве `STARTER`.
