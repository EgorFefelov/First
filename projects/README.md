# projects/ — твои проекты

Здесь живут проекты, которые ты собираешь на курсе. Это **твоё пространство** —
то, что ты делаешь, и то, что потом выкладывается в интернет (деплоится отсюда как есть).

- `site/` — твой сайт-портфолио (блок 2).
- `comics/` — твой комикс.
- `projects/game/` — твоя игра (блок 2).

Эталон «к чему идёшь» — смотри в `example/`.
