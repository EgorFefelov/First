# Проверка готовности к публикации (deploy-check)

Прогон по `projects/` перед выкладкой на прод. Ты **только проверяешь и советуешь** —
ничего не правишь, не запускаешь команд, не блокируешь публикацию.

## Проверки

Пройди все шесть, собери находки в один список.

### 1. 🔴 Ссылки наружу

Grep по `projects/**/*.{html,js,css,json}` на `generated/` и `../..` —
пути, вылезающие за пределы `projects/`. Такие картинки **не поедут на прод**
(на сервер едет только `projects/`).

Совет ученику: «попроси наставника перенести их в `projects/media/`» — БЕЗ автофикса.

### 2. 🔴 Битые ссылки

Каждый `src=`, `href=` и путь-строка в `config.js` должны резолвиться в существующий
файл (включая `../media/…` — относительно файла, где ссылка). Файла нет →
«эта картинка потеряется на сайте».

### 3. 🟡 Точка входа

Есть ли `projects/index.html` с редиректом на `site/` и OG-тегами.
Нет — это не ошибка: «соберём на шаге 4.2».

### 4. 🟡 OG-плейсхолдеры

В OG-тегах `projects/index.html` и `projects/site/index.html`: остались ли
`PLACEHOLDER`, заглушка-аватар, «Тут будут…». Остались → «превью при шаринге
ссылки будет битым или пустым».

### 5. 🟡 Заглушки визитки

В `projects/site/`: «факт о себе», «Тут герой скажет пару слов», «Мой сайт»
и похожая «рыба». Мягко: «сайт выглядит недозаполненным».

### 6. 🟢 Вес

Суммарный размер `projects/media/` (если папка есть). Больше 20 МБ →
«сайт будет грузиться медленно, особенно с телефона — попроси наставника пережать».

## Формат вывода

Список 🔴🟡🟢, каждый пункт: **что нашли → почему важно → что сделать**, детским
языком, без технического дампа. Пример тона:

```
🔴 Игра: 6 картинок лежат вне projects/ — на сайте они будут битыми.
   → попроси наставника перенести их в projects/media/
🟡 В визитке остался «факт о себе» — сайт выглядит недозаполненным.
   → впиши настоящий факт про себя
🟢 Точка входа projects/index.html — есть, редирект и OG на месте.
```

## Финал

- 🔴 нет → «**Можно публиковать!** Дальше — Уровень 4.»
- 🔴 есть → «Можно и так, но лучше починить: …» — публикацию **не блокируешь**,
  решение за учеником и наставником.
