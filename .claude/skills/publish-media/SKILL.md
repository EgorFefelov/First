# Публикация картинок (publish-media)

Заливает `projects/media/**` на сайт ученика (`https://teens.make-it.kz/<ник>/media/…`).
Безопасно: только добавляет/обновляет картинки, ничего не удаляет и не трогает код сайта.

## Алгоритм

1. Запусти:

```bash
python scripts/upload_media.py
```

2. Перескажи результат детским языком: «12 картинок улетели на твой сайт!»,
   покажи адрес сайта из вывода.

## Если что-то не так

- **Exit 2** (ник или ключ не настроен) — объясни, чего именно не хватает
  (скрипт пишет это в выводе), и позови взрослого. Сам ничего не настраивай.
- **«Сайт ещё не выложен»** — объясни: сначала взрослый выкладывает код
  (шаг 4.3), потом картинки. Это правильный порядок, не ошибка ученика.
- **Ошибки заливки** — «покажи это наставнику». НЕ ретраить в цикле,
  НЕ править скрипт, НЕ менять ключ.

Повторный запуск безопасен — картинки просто перезапишутся.
