# Разовая миграция легаси-репо на структуру media/ (migrate-media)

Один раз приводит существующий репо ученика к конвенции `projects/media/<продукт>/`:
находит картинки, на которые ссылается код продуктов, переносит их в `media/`,
точечно переписывает ровно эти пути. Запускает **взрослый/наставник, не ребёнок** —
если просит ученик, вежливо откажи и позови наставника.

## Алгоритм (строгая последовательность)

### 1. Чекпоинт

`git status` — рабочее дерево должно быть чистым. Если нет — **остановись** и
попроси взрослого сначала сохранить работу (скилл `save-progress`).

> **Для кого этот скилл.** Он чинит **старые репо** (потоки 1–2), где артефакты
> ссылались на `generated/experiments/`. На форках с актуальным контрактом такой
> проблемы нет: кадры комикса лежат в `projects/comics/scenes/`, картинки игры —
> в `projects/game/`, пути относительные внутри продукта. Если мигрировать нечего —
> так и скажи взрослому, это нормальный исход.

### 2. Сбор ссылок (два источника, объединить)

- Grep по `projects/**/*.{html,js,css,json}`: атрибуты `src=`, `href=`,
  `url(...)` в CSS, пути-строки с расширениями `.png/.jpg/.jpeg/.webp/.gif`.
- **Только в старых репо** — `state.json`: `comic.frames[].image`,
  `game.hero_sprite`, `game.frames[].{bg,reward}`, `site.avatar`. В актуальном
  контракте этих полей нет, данные продуктов лежат в самих продуктах.

### 3. Фильтр

Мигрируются **только** ссылки из кода `projects/`, которые резолвятся **за пределы**
`projects/` (обычно `../../generated/experiments/…`) — они битые на проде в принципе.

- Ссылки внутрь `projects/` НЕ трогать — уже едут с кодом.
- `state.json` НЕ править вообще: в старых репо панель читает experiments (витрина),
  в новых этих полей уже нет.
- Заводские ассеты шаблона (`projects/game/hero.png`, `projects/game/scenes/placeholder.png`,
  `projects/site/logo-makeit*.png`) НЕ трогать — они в git осознанно.

### 4. Перенос

Для каждого найденного файла:

```
python scripts/webp_convert.py <источник> projects/media/<продукт>/<имя>.webp
```

`<продукт>` — папка продукта, из которой ссылаются (comics/game/site…).
Структура плоская: `media/<продукт>/<файл>`, без вложенных папок.

**Исключение:** аватар, используемый в OG-тегах, — копировать как
`projects/media/site/avatar.png` (PNG без конверта: парсеры мессенджеров
плохо переваривают webp в og:image).

### 5. Правка путей

В каждом файле кода заменить **ровно найденные строки** на
`../media/<продукт>/<имя>.webp` (из `projects/index.html` — `media/…`).
Никаких других правок в этих файлах.

### 6. Отчёт взрослому

- Таблица: файл кода → старый путь → новый путь.
- Список перенесённых файлов с размерами до/после.
- Отдельно 🔴: ссылки, которые резолвятся в НЕсуществующие файлы —
  мигрировать нечего, нужен пересбор картинки.

### 7. Проверка

Прогнать скилл `deploy-check` — категория «ссылки наружу» должна стать пустой.
Предложить взрослому открыть продукты в Live Preview и пройти глазами.

**Коммитить самому НЕЛЬЗЯ** — коммит делает взрослый после проверки.

## Примечание: раскатка на текущих учеников

Репо текущего потока созданы из шаблона ДО появления этого скилла — сам он к ним
не приедет. Порядок: сначала прогон на локальном клоне у Рената (проверка на
реальном легаси), потом либо копирование папок `.claude/skills/migrate-media/` +
`.codex/skills/migrate-media/` в репо учеников, либо запуск прямо из клона.
Канал раскатки — решение Рената по факту прогона.
