# Красота — это выбор, а не список

Учебная точка шага: полировка бесконечна — профессионалы не делают «всё», они **выбирают, что важнее**. Ребёнок играл в свою игру на 2.4 — спроси, что его цепляет: «что бы ты добавил, чтобы было приятнее играть?».

Если идей нет — у тебя есть меню подсказок. Выдавай **по одному**, не списком:

- вспышка при подборе награды;
- плавное появление кадра при переходе;
- лёгкое покачивание героя, когда стоит на месте;
- подсказка «что делать» на кадре;
- счётчик собранного.

Ребёнок выбрал → наставник делает → ребёнок сразу проверяет в игре. Одно улучшение принято — пункт `2.6.visual` закрыт (больше — можно, лимит ниже).

# Звук из ничего

Момент-вау шага: звук в игре можно **синтезировать кодом** — без единого звукового файла. Компьютер сам поёт нужную ноту.

Спроси ребёнка про характер звука: подбор награды — это «дзинь» или «бульк»? Высокий или низкий? Вставь рецепт (блок наставника ниже), дай послушать, покрути частоту и длительность по реакции.

Минимум для закрытия пункта `2.6.sound`: звук подбора награды + звук финала. Звук перехода между кадрами — по желанию.

# Имя игры

У каждого продукта есть имя — без имени игру нельзя никому показать. Брейншторм от сюжета и героя: как зовут героя? про что игра одним словом? что игрок делает?

Решение ребёнка **финально** — любое, даже странное. «Суперкот против тумана» — отличное название, если его выбрал автор.

Название идёт на титульный экран: ребёнок открывает игру и видит **название на стартовом экране**. Пункт `2.6.title` закрыт.

## Для наставника: рецепт звука (WebAudio)

Вставить в конец `projects/game/assets/core.js`. Сниппет полный, копируемый — не сочиняй с нуля. Функции вешаются на `window`, чтобы их видели и ядро, и модули:

```js
// --- звук: WebAudio-синтез, без файлов ---
// один AudioContext, лениво: браузер разрешает звук только после жеста пользователя
let audioCtx = null;
function ensureAudio() {
  if (!audioCtx) audioCtx = new (window.AudioContext || window.webkitAudioContext)();
  if (audioCtx.state === "suspended") audioCtx.resume();
  return audioCtx;
}

// одна нота: частота (Гц), длительность (мс), форма волны
function beep(freq, durMs, type = "sine") {
  const actx = ensureAudio();
  const osc = actx.createOscillator();
  const gain = actx.createGain();
  osc.type = type;
  osc.frequency.value = freq;
  gain.gain.setValueAtTime(0.15, actx.currentTime);
  gain.gain.exponentialRampToValueAtTime(0.001, actx.currentTime + durMs / 1000);
  osc.connect(gain);
  gain.connect(actx.destination);
  osc.start();
  osc.stop(actx.currentTime + durMs / 1000);
}

window.soundPickup  = () => beep(880, 120, "triangle");          // подбор награды
window.soundAdvance = () => beep(440, 80, "sine");               // переход кадра
window.soundFinish  = () => { beep(523, 150); setTimeout(() => beep(784, 280), 160); }; // финал
```

**Точки вызова под модульный движок** (важно — звук зовётся из ядра и модулей,
каждый в своей точке):

- `soundPickup()` — в модуле `projects/game/assets/modules/inventory.js`, в `update`, там
  где награда добавляется в `collected` (`collected.add(...)`).
- `soundAdvance()` — в модуле `projects/game/assets/modules/transitions.js`, в `onAction`,
  сразу перед/после `GameAPI.gotoNext()` (момент смены кадра). Альтернатива —
  в ядре `core.js` внутри `GameAPI.gotoNext()` при `sceneIndex++`.
- `soundFinish()` — в модуле `projects/game/assets/modules/overlays.js`, в
  `window.onGameFinish` (где показывается финальный оверлей).

Везде — через `window.soundPickup?.()` (optional-call), чтобы код модуля не падал,
если рецепт звука ещё не вставлен.

Крутить по реакции ребёнка: частота (`880` выше/ниже), длительность, форма волны (`"sine"` мягкий, `"triangle"` звонкий, `"square"` 8-битный). Громкость — `0.15` в `setValueAtTime`, больше 0.3 не ставить.

## Для наставника: визуальные рецепты

Точки вставки в движке — для каждого пункта меню. ВАЖНО: код движка теперь разнесён
по ядру (`core.js`) и модулям (`assets/modules/`) — правь там, где живёт нужная часть:

- **Вспышка при подборе** — анимация подбора уже есть (`pickupAnimMs` в конфиге): усилить — в момент подбора нарисовать расходящийся круг (radius по времени, globalAlpha вниз). Подбор живёт в механике/инвентаре.
- **Плавное появление кадра** — alpha-fade фона: в ядре `core.js` при `resetScene()` запомнить время, в `draw()` первые ~400мс рисовать фон с нарастающим `globalAlpha`.
- **Покачивание героя на месте** — в `core.js` `draw()` к `y` героя добавить `Math.sin(performance.now()/400) * 4`, когда скорость ~0.
- **Подсказка на кадре** — текстовая плашка по образцу `drawHintPill` (приватный хелпер в `transitions.js`).
- **Счётчик собранного** — текст `N/M` рядом с инвентарём (в `inventory.js` `draw`), числа из `collected.size` и `REWARD_SLOTS.length`.

Правки **локальные, по одной**, после каждой — проверка запуском. Не правь два эффекта разом.

## Для наставника: граница шага

**Не более 2-3 улучшений за сессию** — иначе залипание в полировку. Хотелки сверх лимита — записать в `note` пункта `visual` («в следующий раз») и честно сказать ребёнку, что они в списке.

## Для наставника: типичные тупики

- **Хочет «как в настоящих играх»** (частицы, шейдеры, анимация скелета) → честно: «это можно, но долго — выбери одну штуку, которая важнее всего». Одну — делаем.
- **Звук раздражает** → убавь громкость, смени частоту вниз, или выключи совсем. Звук не обязан нравиться — но пункт `sound` закрывается самой попыткой: звук был, ребёнок решил.
- **Не может придумать название два захода** → отложи на конец сессии, вернись после контрольного прогона — после «своей» игры название обычно приходит само.
