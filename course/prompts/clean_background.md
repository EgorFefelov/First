# Промпт-канон: чистый фон из кадра комикса

Убрать героя с кадра комикса — получить чистую сцену для игры
(`projects/game/scenes/scene_<N>.png`). Шпаргалка для наставника.

## Тул

`mcp__nano-banana__edit_image`. Референс — кадр комикса ребёнка
(`generated/experiments/comic_*.png`). Оригинал кадра не трогать — работаем с копией результата.

## Шаблон промпта

> убери [героя — назвать так, как он выглядит на кадре: «мальчика в синей куртке»]
> с картинки, дорисуй фон на его месте, всё остальное оставь без изменений

## Правила

- Один кадр за вызов. Не пытаться чистить несколько сцен одним промптом.
- НЕ менять стиль и освещение — просить только убрать героя.
- Результат должен сохранить пропорции кадра (фон ляжет на канвас игры).
- Если на кадре есть другие персонажи — они остаются, убираем только героя.

## Что делать с результатом

1. Сохранить как `projects/game/scenes/scene_<N>.png`, где N — порядок кадра в истории
   (по `state.comic.frames`, с единицы).
2. Обрезатель НЕ нужен — фон остаётся непрозрачным, это сцена целиком.
3. Отметить кадр в `state.game.frames[i].bg`.
