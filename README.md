# make it, teens — интерактивный курс

Форкаемый шаблон для одного ребёнка (10–17 лет). Внутри форка — наставник (`.claude/CLAUDE.md`), методички (`course/content/`), интерактивная оболочка с Баблом и пространство проектов ученика.

Ребёнок проходит:

- **Уровень 0** — знакомство с AI.
- **Уровень 1** (1.1 → 1.4) — промпт → свой герой → история → комикс.
- **Уровень 2** (2.1 → 2.7) — разбирает комикс и пересобирает в игру; на 2.7 в неё играет другой ученик (первый юзертест).
- **Уровень 3** (3.0 → 3.8) — собирает личный сайт-портфолио из своих проектов: hero → проекты → навыки → где я; карточки соединяются с его комиксом и игрой. Сайт работает локально.
- **Уровень 4** (4.0 → 4.4) — публикует сайт в интернет на `teens.make-it.kz/<ник>`: проверяет готовность → выкладывает (взрослый) → проверяет вживую на проде → делится ссылкой. Продукт выходит к первым зрителям. Финал блока.
